# Regression Experimental

This project compares several regression models.

## Models used

- Lasso Regression
- Ridge Regression
- K-Nearest Neighbors

## Purpose

The goal is to predict insurance payments and compare model performance.

## Explanation
The experimental used 3 types of algorithms; Lasso, Ridge and K-nearnest neighbor on predicting the insurance paid by the customers.
